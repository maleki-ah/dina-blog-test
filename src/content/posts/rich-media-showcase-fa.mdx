بیشتر پست‌های دینا مارک‌داون ساده هستند تا نوشتن سریع بماند. وقتی پستی به بیشتر از این نیاز داشته باشد به فایل `.mdx` تبدیل می‌شود و می‌تواند از کامپوننت‌های نگارش آزمایشگاه استفاده کند. این صفحه یک مرجع زنده است: هر چیزی که در ادامه می‌بینید دقیقاً همان چیزی است که نویسنده می‌نویسد.

## ویدیوی جاسازی‌شده

ضبط گفتگوها، دموها و درس‌گفتارها با یک خط جاسازی می‌شوند. کامپوننت یک لینک یوتیوب یا ویمئو را به یک پخش‌کنندهٔ واکنش‌گرا و کم‌بار تبدیل می‌کند و آن را چپ‌به‌راست نگه می‌دارد تا داخل پست‌های فارسی هم درست بنشیند.

```python
def fedavg(client_weights: list[list[float]], samples: list[int]) -> list[float]:
    """Weighted average of client models, weighted by sample count."""
    total = sum(samples)
    return [
        sum(n / total * w for n, w in zip(samples, dim))
        for dim in zip(*client_weights)
    ]
```

## نویسندگان چطور از این‌ها استفاده می‌کنند

- برای متن ساده، فرمول یا نوتبوک، مارک‌داون بنویسید.
- برای بقیه، فایل را به `.mdx` تغییر دهید و فقط همان کامپوننت‌هایی را import کنید که پست لازم دارد — کامپوننت‌های استفاده‌نشده هرگز بارگذاری نمی‌شوند.
- ویدیو، شکل و تب همگی به زبان و جهت خود پست می‌مانند؛ پس یک نمونهٔ انگلیسی داخل سایت فارسی درست کار می‌کند و برعکس.
